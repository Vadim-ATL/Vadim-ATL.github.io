# Vadim Atlassov

Personal academic homepage, built with Jekyll and hosted at [vadim-atl.github.io](https://vadim-atl.github.io).

## Editing

- `index.md`: biography, publications and manuscripts, research projects, news, and contact links. Explicit front matter selects the default layout.
- `_layouts/default.html`: document shell and navigation.
- `assets/css/custom.css`: all styling, with a compact desktop reading layout.
- `assets/`: original portrait and research figures. Figure links open the full-resolution originals.
- `_config.yml`: Jekyll configuration.

No JavaScript, external fonts, or frontend frameworks are required. Keep authorship, contribution statements, and manuscript status accurate when updating entries.

## Preview and deployment

With Jekyll installed, run `jekyll serve` and open `http://localhost:4000`.
GitHub Pages builds and deploys from `main` on push.
